# Vidéos déposées

Chaque vidéo déposée ici est inscrite « à traiter » dans `07_ASSETS/A_TRAITER.md`. L'agent la range : enregistrement
d'écran → `screen-records/<thème>/<thème>-<date>-S<n>.<ext>` + `SCREENS.md` + `opinions.json` ; rush de réaction →
`rushes/reaction-<qui>-<lieu>-<fichier>` ; puis coche la ligne. Les vidéos ne sont pas versionnées (`.gitignore`).
